# Network / Classroom / Office Technology Labs

## Lab 27 — Network Troubleshooting
Simulate a workstation with no network access.

Practice:
- Physical/link status
- IP address
- Default gateway
- DNS
- DHCP
- Ping
- Traceroute
- Local vs internet connectivity
- Document findings

## Lab 28 — DNS/DHCP Incident
Create a test network where clients receive incorrect or missing network configuration.

Identify:
- DHCP issue
- DNS issue
- Client issue
- Gateway issue

Restore service and validate multiple clients.

## Lab 29 — Printer Troubleshooting
Scenario: Faculty member cannot print.

Check:
- Printer power/network
- Queue
- Driver
- Default printer
- IP address
- Paper/toner
- Authentication
- Test page

## Lab 30 — Projector/Display Failure
Scenario: Classroom Mac/Windows PC cannot display on projector.

Test:
- Input source
- Cable
- Adapter
- Resolution
- Display detection
- Power
- Alternate device
- Workaround

## Lab 31 — Classroom Technology Pre-Flight
Create a checklist for a classroom before the school year:
- Computer
- Display/projector
- Speakers
- Camera
- Microphone
- Network
- Power
- Printer if applicable
- Software
- Updates
- Accessibility features

## Lab 32 — Telephone/VoIP Troubleshooting
Scenario: Office phone has no audio.

Practice:
- Power
- Network
- Registration
- Handset
- Call path
- Test inbound/outbound calls
- Escalate to telecom/vendor when required
