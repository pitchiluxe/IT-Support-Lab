# IT Services Support Technician — Real-World Lab Program

This lab program is built directly from the Westminster Schools IT Services Support Technician job description supplied by the user.

## Goal
Build practical, interview-ready experience across:
- Apple/macOS/iOS/iPadOS support
- Windows desktop support
- Google Workspace administration and troubleshooting
- Ticketing, SLA, escalation, documentation and customer service
- JAMF/MDM concepts
- Classroom and office technology
- Hardware inventory, repair, RMA and lifecycle management
- System builds, upgrades and deployment
- Networking and troubleshooting
- Technology projects and change management
- End-user training
- Incident response and post-resolution follow-up

## Suggested lab environment
Use a combination of:
1. Windows 11 VM
2. macOS device/VM where legally and technically supported
3. iPhone/iPad if available
4. Google Workspace test tenant or a safe personal/test environment
5. JAMF Now or another MDM training environment where available
6. A ticketing platform such as GLPI, Zammad, Freshservice trial, or another lab-safe system
7. A small virtual network using VMware/VirtualBox
8. Test printer and/or simulated printer troubleshooting
9. Optional managed switch/router lab

## Safety
Do not experiment against a production school, employer, customer, or public network. Use test accounts, test devices, VMs, and isolated networks.

## Recommended execution
Complete the labs in order. For every lab, produce:
- Ticket/incident record
- Diagnosis
- Evidence collected
- Action taken
- Validation test
- User communication
- Knowledge-base/documentation update
- Escalation decision, when applicable

The final capstone combines multiple skills into a simulated school-wide support operation.
