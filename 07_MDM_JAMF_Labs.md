# MDM / JAMF Labs

## Lab 22 — MDM Device Enrollment
Using a safe training environment, enroll a test Apple device.

Document:
- Device identity
- Enrollment method
- Ownership
- Assigned user
- Configuration profile
- Compliance state

## Lab 23 — Configuration Profile
Create a test policy for:
- Wi-Fi
- Passcode
- Restrictions
- Approved settings

Test on a pilot device before broader deployment.

## Lab 24 — Application Deployment
Deploy one approved test application.

Measure:
- Deployment success
- Failure reason
- Version
- Device population
- Recovery procedure

## Lab 25 — Device Compliance
Create a simple compliance workflow:
- Identify noncompliant devices
- Notify user
- Remediate
- Verify
- Document

## Lab 26 — Lost Device
Simulate a lost school iPad and execute the approved MDM response.

Important: perform only against devices/accounts you own or are explicitly authorized to administer.
