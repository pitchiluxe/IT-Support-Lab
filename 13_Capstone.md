# Final Capstone — Simulated School IT Services Support Operation

## Scenario
You are the lead support technician for a fictional K-12 school with faculty, staff, students and parents.

At 7:15 AM on a school day:
- Three classrooms report projector problems.
- Five faculty members report Google Drive access problems.
- Two iPads are not receiving required applications.
- A Windows workstation is extremely slow.
- One printer is offline.
- A faculty Mac cannot connect to Wi-Fi.
- A vendor reports a pending replacement device.
- The CIO asks for a status report.
- A parent calls about an account access issue.

## Your mission
Run the operation as if you were the real support technician.

### Required outputs
1. Ticket queue
2. Priorities and SLA reasoning
3. Initial user communications
4. Troubleshooting notes
5. Escalation records
6. Asset/inventory updates
7. Vendor communication
8. Classroom workaround
9. Resolution validation
10. User follow-up
11. Knowledge-base update
12. CIO status report
13. End-of-day metrics
14. Lessons learned
15. Recommendations for workflow/process improvement

## Final review questions
- Did you prioritize by instructional/business impact?
- Did you maintain professional customer service?
- Did you document every important action?
- Did you test solutions instead of assuming they worked?
- Did you know when to escalate?
- Did you maintain asset information?
- Did you protect user data?
- Did you communicate clearly with technical and nontechnical people?
- Did you identify systemic issues?
- Did you propose process improvements?

## Interview preparation
Be able to explain one completed lab using this structure:

**Situation → Impact → Diagnosis → Actions → Validation → Customer Communication → Documentation → Prevention**

Do not claim production experience from these labs. Describe them as hands-on lab simulations and explain exactly what you configured, tested and learned.
