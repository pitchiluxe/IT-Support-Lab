# Documentation / Training Labs

## Lab 42 — Knowledge Base
Write KB articles for:
1. Cannot connect to Wi-Fi
2. Printer not printing
3. Gmail missing message
4. Google Drive access denied
5. Projector no signal
6. macOS application will not launch
7. Windows computer slow

Each article should include:
- Symptoms
- Cause
- Resolution
- Validation
- Escalation conditions

## Lab 43 — End-User Training
Deliver a 10-minute training session to fictional faculty.

Choose:
- Google Drive sharing
- Gmail productivity
- Classroom display setup
- iPad basics
- Security awareness

Measure whether users can complete a practical task afterward.

## Lab 44 — Post-Resolution Follow-Up
Take five completed incidents and perform simulated follow-ups.

Document:
- Did the solution remain effective?
- Is the user satisfied?
- Was documentation adequate?
- Is there a recurring problem?
- Should a project/problem record be created?
