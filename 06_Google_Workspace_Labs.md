# Google Workspace Labs

## Lab 17 — Gmail Troubleshooting
Scenario: Faculty member says messages are missing.

Investigate:
- Search
- Spam/trash
- Filters
- Forwarding
- Storage
- Browser/session
- Another client/device
- Organizational service status in the test environment

## Lab 18 — Google Drive Permission Problem
Scenario: Teacher cannot open a shared curriculum document.

Practice:
- Identify owner
- Review sharing model
- Verify correct account
- Test permissions
- Correct access safely
- Explain sharing best practices

## Lab 19 — Drive Sync Issue
Scenario: Files appear on the web but not locally.

Practice:
- Determine whether issue is browser, sync client, storage, account or permissions
- Collect evidence
- Restore synchronization
- Validate with test file

## Lab 20 — Account/Login Incident
Scenario: User cannot authenticate.

Practice:
- Verify identity using the organization's approved process
- Distinguish password, MFA, browser, account status and service issues
- Escalate security-sensitive events properly

## Lab 21 — Faculty Google Workspace Training
Create a 15-minute training session covering:
- Gmail search
- Drive organization
- Sharing permissions
- Calendar basics
- Security awareness
- Where to request support
