# Windows Support Labs

## Lab 06 — Windows 11 Slow Computer
Troubleshoot:
- CPU/RAM/disk utilization
- Startup applications
- Windows Update
- Event Viewer
- Storage
- Malware/security status in a safe test VM
- Network performance

Deliverable: documented root cause and validation.

## Lab 07 — Application Will Not Launch
Practice:
- Reproduce error
- Check event logs
- Repair/reset application
- Verify dependencies
- Test user profile
- Reinstall only when justified

## Lab 08 — Windows User Profile Problem
Scenario: User signs in but desktop/settings are corrupted.

Practice:
- Determine whether issue is account or local profile
- Preserve user data
- Create safe backup
- Repair profile or create replacement
- Validate applications and files

## Lab 09 — Build a Standard Windows Workstation
Create a repeatable build checklist:
- OS installation
- Updates
- Naming convention
- Local/admin controls
- Required applications
- Browser
- Security settings
- Printer
- Network
- User testing
- Asset record

## Lab 10 — Windows Upgrade
Simulate upgrading a test Windows machine.
Practice:
- Pre-check
- Backup
- Compatibility
- Change window
- Upgrade
- Driver/application validation
- Rollback plan
- User communication
