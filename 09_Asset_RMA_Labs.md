# Asset / Repair / RMA Labs

## Lab 33 — Inventory Audit
Create a fictional inventory of 30 devices.

Track:
- Asset ID
- Serial number
- Device type
- Model
- Assigned user
- Location
- Purchase date
- Warranty
- Condition
- Status

Perform a physical-vs-database reconciliation.

## Lab 34 — Hardware Diagnosis
Scenario: Laptop battery is failing.

Practice:
- Collect symptoms
- Run diagnostics
- Determine repair vs replacement
- Preserve data
- Update asset record
- Communicate timeline

## Lab 35 — RMA Workflow
Simulate sending a defective device to a vendor:
- Verify warranty
- Collect serial/asset information
- Capture failure evidence
- Obtain RMA
- Package/ship
- Track status
- Receive replacement
- Update inventory
- Validate device

## Lab 36 — Damaged Equipment / Insurance
Scenario: School-owned laptop is physically damaged.

Practice:
- Incident report
- Photos/evidence
- Asset record
- Data protection
- Repair estimate
- Vendor/insurance workflow
- Replacement decision process
