# Apple / macOS / iOS / iPadOS Labs

## Lab 11 — macOS No Internet
Troubleshoot:
- Wi-Fi
- DHCP
- DNS
- Network configuration
- Captive portal/authentication
- Compare with another device

## Lab 12 — macOS Performance Issue
Investigate:
- CPU/memory pressure
- Storage
- Login items
- Application behavior
- Updates
- Logs

Document evidence before making changes.

## Lab 13 — macOS User Account/Application Issue
Scenario: Faculty member cannot launch a required application.

Practice:
- Reproduce
- Check permissions
- Check application version
- Check disk space
- Test another user
- Repair/reinstall if appropriate
- Validate

## Lab 14 — iPad Enrollment Troubleshooting
Simulate a school-owned iPad:
- Enrollment
- Wi-Fi
- Apple account/managed account concepts
- Required apps
- Restrictions
- Passcode policy
- Inventory record

## Lab 15 — iPhone/iPad Lost Device Workflow
Practice a simulated lost-device procedure:
- Verify asset
- Record incident
- Notify appropriate team
- Apply approved MDM lost-device controls
- Protect organizational data
- Document chain of events
- Close only after confirmation

## Lab 16 — Apple OS Upgrade Project
Build a deployment plan for upgrading a fleet of Macs/iPads:
- Inventory
- Compatibility
- Pilot group
- Backup
- Communication
- Maintenance window
- Deployment
- Validation
- Exception handling
- Rollback/escalation
